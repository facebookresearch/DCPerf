# liblinear

Benchpress integration of [liblinear](https://github.com/cjlin1/liblinear), NTU's library
for large-scale linear classification. The benchmark builds liblinear's `train`/`predict`
CLIs from a pinned upstream release, trains an L2-regularized L2-loss SVC on either a
synthetic or a real [LIBSVM](https://www.csie.ntu.edu.tw/~cjlin/libsvmtools/datasets/)
dataset, and reports training time, derived throughput (instances/sec), and prediction
accuracy.

## Pinned version

The install script builds tag **`v249`** of `github.com/cjlin1/liblinear`. To upgrade, bump
`LIBLINEAR_TAG` in `install_liblinear.sh` and this README.

## Datasets

- **synthetic** — generated by `gen_dataset.py` (stdlib only). Arbitrary size via
  `--samples`, `--features`, `--density`, `--noise`, `--seed`. A random ground-truth
  hyperplane produces linearly-separable `+1/-1` labels (with optional label noise).
- **real LIBSVM sets** — `rcv1` (downloaded by default), plus `a9a`, `ijcnn1`, `w8a`
  (downloaded on demand the first time they are run). Heavier sets are intentionally not
  downloaded automatically.

## Usage

```bash
# Synthetic, default arbitrary size
./benchpress_cli.py install liblinear_synthetic
./benchpress_cli.py run liblinear_synthetic

# Override synthetic size / shape
./benchpress_cli.py run liblinear_synthetic -i '{"samples": "500000", "features": "2000"}'

# Override solver / cost / bias
./benchpress_cli.py run liblinear_synthetic -i '{"solver": "2", "cost": "0.5", "bias": "1"}'

# Real rcv1.binary dataset
./benchpress_cli.py install liblinear_rcv1
./benchpress_cli.py run liblinear_rcv1
```

## Reported metrics

| Metric | Meaning |
|--------|---------|
| `train_time_sec` | Wall-clock time of `train` |
| `throughput_instances_per_sec` | `train_instances / train_time_sec` |
| `accuracy_pct` | Prediction accuracy on the test set |
| `train_instances` | Number of training rows |
